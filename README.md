# Raheel Siddiqui — Portfolio Website

A professional portfolio site, ready to deploy on GitHub Pages.

## Structure
- `index.html` — the main profile page (HTML/CSS/JS in one file)
- `resume.html` — the résumé library page (specialty picker + inline PDF viewer)
- `assets/` — profile photo
- `media/` — video appearances (mp4)
- `resumes/` — all specialty résumé PDFs, viewed inline via resume.html

## Deploy
See the deployment steps provided in chat, or:
1. Create a GitHub repo
2. Upload index.html, resume.html, and the assets/, media/, resumes/ folders
3. Turn on GitHub Pages (Settings → Pages → deploy from main branch, root folder)
4. Your site goes live at https://<username>.github.io/<repo-name>/
